How to read a report

  • A connection is a filed fact: a board seat, a stake, a contract, a contribution. It says nothing about intent. Connected is not guilty.
  • A Balance flag is a signal for review, set beside a published standard. It is not a finding of wrongdoing.
  • The full report is built by the page itself from the public map. No person has read each one through before it appears. It says so at its top.
  • The map is still being built. Missing is not the same as clean.
  • Any report can be saved or printed as a PDF from the button at its top. It carries a fingerprint so a copy can be checked against the records.
